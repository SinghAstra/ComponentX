# Component-X

A component library, its CLI, and the docs site — organized as a pnpm monorepo.

## Layout

- `apps/www/` — Next.js docs and showcase site
- `packages/cli/` — `@component-x/cli`, the installer CLI
- `packages/ui/` — `@component-x/ui`, the component library (planned)

## Development

Requires Node 20+ and pnpm.

\`\`\`
pnpm install
pnpm dev
\`\`\`
